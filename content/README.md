# 단어와 맵

화면에 나오는 모든 것이 여기 있습니다. 데이터베이스가 아니라 파일입니다.

## 단어를 더하거나 고치려면

1. GitHub 에서 `content/sets/` 안의 파일을 엽니다 (세트 하나에 파일 하나).
2. 연필 모양(Edit) 을 누릅니다.
3. 한 줄에 단어 하나씩 적습니다. **단어와 뜻 사이는 탭입니다.**
   ```
   cave	동굴
   however	그러나
   ```
   엑셀이나 표에서 복사해 붙여넣으면 탭이 그대로 들어갑니다.
4. 맨 아래 **Commit changes** 를 누릅니다.

1~2분 뒤 사이트에 반영됩니다.

## 새 세트를 만들려면

`content/sets/` 에서 **Add file → Create new file** 을 누르고 이름을
`J3.tsv` 처럼 짓습니다. 첫 줄에 `# J3` 이라고 적으면 그것이 화면에 보이는
세트 이름이 됩니다.

## 규칙

- 맨 앞이 `#` 인 줄과 빈 줄은 무시합니다. 메모를 적어 두어도 됩니다.
- 칸은 **단어 · 뜻 · 품사** 순서입니다. 품사는 없어도 됩니다.
- 뜻을 비워 두어도 단어는 올라갑니다. 나중에 채우면 됩니다.
- 쉼표가 아니라 탭으로 나누는 이유는 뜻에 쉼표가 자주 들어가서입니다
  (`문제, 쟁점`).

## maps/

영영 풀이·예문·연어가 든 파일입니다. 예전에 AI 로 만들어 검수한 것을
그대로 옮겨 왔습니다. 손으로 고칠 일은 거의 없습니다.

## export.json

Neon 데이터베이스에서 한 번 옮겨 올 때 쓴 원본입니다. 기록으로 남겨 둡니다.
`node scripts/export/split.mjs` 가 이 파일을 위의 두 폴더로 가릅니다.
